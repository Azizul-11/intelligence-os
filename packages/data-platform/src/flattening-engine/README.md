# Flattening Engine

## Purpose

The Flattening Engine converts hierarchical or structured datasets into a universal flat row representation.

It prepares normalized datasets for warehouse ingestion.

## Responsibilities

- Flatten nested structures
- Produce universal rows
- Preserve canonical field mappings
- Generate flattened records

## Non-Responsibilities

- Validation
- Normalization
- Entity Resolution
- Warehouse loading

This module is completely domain-independent.

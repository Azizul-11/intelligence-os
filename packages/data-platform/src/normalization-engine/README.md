# Normalization Engine

## Purpose

The Normalization Engine converts heterogeneous datasets into the canonical IntelligenceOS vocabulary.

It standardizes field names, aliases and canonical values before entity resolution.

The engine never performs entity matching.

That responsibility belongs to the Entity Resolution module.

## Responsibilities

- Field normalization
- Alias normalization
- Canonical mapping
- Value normalization
- Mapping reports

This module is completely domain-independent.

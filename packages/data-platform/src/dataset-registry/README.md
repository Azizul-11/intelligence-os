# Dataset Registry

## Purpose

The Dataset Registry tracks logical datasets within IntelligenceOS.

Unlike the Raw File Registry, which manages physical files,
the Dataset Registry represents datasets as reusable business assets.

A dataset may consist of one or more files and can evolve through
multiple versions over time.

Examples include:

- Healthcare Quality Dataset
- School Performance Dataset
- Financial Reports
- Climate Measurements
- Manufacturing Metrics

The registry stores ownership, versions, tags, and metadata while
remaining independent of any specific domain.

# Warehouse Builder

## Purpose

The Warehouse Builder converts flattened records into the canonical IntelligenceOS warehouse model.

It prepares entities, metrics and narratives for persistence.

## Responsibilities

- Build warehouse records
- Build warehouse batches
- Preserve canonical mappings
- Prepare warehouse payloads

## Non-Responsibilities

- Validation
- Normalization
- Entity Resolution
- Data ingestion

This module is domain-independent.

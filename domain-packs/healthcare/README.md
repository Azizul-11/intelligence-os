# Healthcare Domain Pack

The Healthcare Domain Pack is the first implementation of the IntelligenceOS Domain SDK.

It teaches the platform healthcare-specific knowledge while keeping the core platform completely domain-agnostic.

This package contains:

- Metadata
- Entities
- Metrics
- Aliases
- Ontology
- Relationships
- Benchmarks
- SQL Templates
- Capabilities
- Recommendations

The pack conforms to the Domain SDK contracts and can be loaded by the Domain Registry.

Future domain packs (Education, Finance, Climate, Manufacturing, etc.) will follow the exact same structure.
